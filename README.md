# STUDIO ON — 샘플 데모

홈페이지·웹앱 제작 결과물을 실제로 눌러 볼 수 있게 올려 둔 정적 데모입니다.

- `/` — 샘플 목록
- `/landing/` — 원페이지 랜딩페이지 샘플 (ATELIER LUNE, 가상의 스튜디오)
- `/reservation/` — 예약·고객관리 웹앱 샘플
  - `?view=dash` PC 대시보드 / `?view=booking` 모바일 예약
  - `reservation/dash.html`, `reservation/booking.html` 은 원본 크기 화면

등장하는 상호, 주소, 이름, 연락처는 모두 가상이며 실제 결제나 예약은 이루어지지 않습니다.
빌드는 정적 파일 그대로이고, 폰트는 Pretendard(SIL OFL)와 Noto Sans/Serif KR(SIL OFL) 서브셋입니다.
